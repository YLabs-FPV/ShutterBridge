import { BOARD_NAME } from "../../../consts";

ShutterBridge está pensado para la **{BOARD_NAME}** (ESP32-S3FH4R2: 4 MB de flash, 2 MB de PSRAM,
USB nativo). Otras placas ESP32-S3 pueden funcionar, pero no están probadas.

<img src="/docs/hardware/esp32-s3.webp" style={{ height: "150px" }} alt="Placa Waveshare ESP32 S3 Mini" />

## Necesitarás

- La placa {BOARD_NAME}.
- Un controlador de vuelo con **Betaflight 2025.12 o posterior** y un
  UART libre.
- Una cámara de acción compatible - una DJI Osmo / Action, o una GoPro HERO9 o posterior.
- Un cable USB-C con datos para instalar.
- Un soldador y conocimientos básicos de soldadura.

Consulta la [tabla de compatibilidad](/docs/compatibility) para ver la matriz completa de cámaras compatibles.
