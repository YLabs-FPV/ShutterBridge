import { BOARD_NAME } from "../../../consts";

ShutterBridge розрахований на **{BOARD_NAME}** (ESP32-S3FH4R2: 4 МБ флеш, 2 МБ PSRAM,
нативний USB). Інші плати ESP32-S3 можуть працювати, але не перевірені.

<img src="/docs/hardware/esp32-s3.webp" style={{ height: "150px" }} alt="Плата Waveshare ESP32 S3 Mini" />

## Тобі знадобиться

- Плата {BOARD_NAME}.
- Польотний контролер з **Betaflight 2025.12 або новіше** та
  вільним UART.
- Сумісна екшн-камера - DJI Osmo / Action або GoPro HERO9 чи новіша.
- Кабель USB-C з підтримкою даних для прошивки.
- Паяльник і базові навички паяння.

Дивись [таблицю сумісності](/docs/compatibility), щоб побачити повну матрицю сумісних камер.
